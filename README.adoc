== About

Configures, builds, and runs a remote server that hosts Transmission,
OpenVPN, and Nginx.

== Install

[,sh]
----
git clone https://github.com/rdavid/argus.git &&
  cd ./argus &&
  cat <<EOT >> cred.env
USER=[username]
PASS=[password]
URL=[url]
EOT
sudo docker-compose up -d
----
